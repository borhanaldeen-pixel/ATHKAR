# الأذكار اليومية - حصن المسلم (PWA)

تطبيق ويب تقدمي يعمل دون إنترنت ويُثبَّت على الجوال والحاسوب.

## محتويات المجلد
- index.html : التطبيق
- manifest.webmanifest : بيانات التثبيت (الاسم، الأيقونات، الاختصارات)
- sw.js : خدمة العمل دون إنترنت
- icons/ : أيقونات التطبيق (عادية + maskable + آيفون)
- assets/ : Tailwind والخطوط وFont Awesome بنسخ محلية (لا يحتاج أي CDN)

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع **محتويات** هذا المجلد (وليس المجلد نفسه) إلى الفرع main.
2. من Settings ثم Pages اختر Deploy from a branch ثم main ثم root ثم Save.
3. افتح الرابط https://USERNAME.github.io/REPO/ على الجوال.
4. أندرويد/كروم: الإعدادات داخل التطبيق ثم «تثبيت على الجهاز» (أو قائمة المتصفح ثم تثبيت التطبيق).
   آيفون/سفاري: زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

يجب فتح التطبيق عبر https (أو localhost) ليعمل التثبيت والعمل دون إنترنت، ولا يعمل بالنقر المباشر على index.html.

## التجربة محلياً
    python3 -m http.server 8080
ثم افتح http://localhost:8080

## عند تعديل أي ملف
غيّر رقم VERSION في أول sw.js (مثلاً adhkar-pwa-v2) ثم ارفع الملفات؛ فيصل التحديث للمستخدمين تلقائياً.

## ملاحظات
- القراءة الصوتية بصوت القارئ تحتاج إنترنت (الملفات الصوتية لا تُخزَّن في التطبيق).
- بقية الميزات (العدادات، المسبحة، السمات، الخطوط) تعمل دون اتصال.
